# Local PSI comparison evidence

This is a local, real-model cohort comparison. It is not a measurement of live
production traffic or proof of a production alert.

## Provenance and selection

- Model identifier in both scored files: `aubmindlab/bert-base-arabertv02-official-full-gpu-seed-42`.
- Reference source: `data/processed/test.csv`, 10,570 rows, SHA-256
  `981acfe2f56823fe4a310d70fe7b09cce6a304ec8e3de2978f6d48a0e79a27cf`.
  The first 1,000 unique normalized reviews in source order were scored with the
  official local model. Reference IDs identify their source row positions.
- Current source: 1,000 rows from the local real-review sample
  `data/scoring/input/real_reviews_sample.csv`, SHA-256
  `618c3c4e183124326b5c9dadc0a14f5a2c862444be7632eb359125fa93e40d26`.
  All 1,000 source IDs matched the `no` identifiers in the local unbalanced
  source, SHA-256
  `fc3bb8210d4f8a658b77c92fe659e532173432679992d5ae1e6c91969681748b`.
  The existing real-model output had 1,000 rows, matching source IDs in order,
  finite confidence scores in `[0, 1]`, and the same official model identifier.
- To keep cohorts disjoint, 25 current rows whose normalized text occurred
  anywhere in the reference test split were excluded. Seven additional rows
  repeating a normalized current review were excluded, retaining the first
  eligible source occurrence. The current cohort contains 968 distinct
  normalized reviews and has zero normalized-text overlap with the reference
  split.

## Measured result

| Reference rows | Current rows | PSI | Threshold | Alert |
| ---: | ---: | ---: | ---: | :--- |
| 1,000 | 968 | 0.7600917779274092 | 0.25 (strictly greater) | Yes |

The checker exited with code 1 because the measured PSI exceeds the configured
threshold. The threshold and calculation were not changed. This result
describes differences between these two local cohorts only; it does not
establish temporal drift in production traffic.

review text. The report contains only aggregate counts, filenames, hashes, PSI,
threshold, and alert status. These local data artifacts are not committed; the
summary above preserves the measured result without review text.

## Runtime limitation

Prometheus and Grafana are now wired into `compose.yaml`, and the FastAPI
metrics endpoint reads the persisted JSON report. Docker Compose and `promtool`
were unavailable in the verification environment, so container startup,
Prometheus scraping, and the Grafana UI/dashboard have not been runtime-tested.
No Grafana screenshot or live alert evidence has been captured.
